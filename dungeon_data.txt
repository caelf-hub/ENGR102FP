# ---- THE DUNGEON ----
# The dungeon is one map made of cell_cols x cell_rows cells, each cell_width x cell_height tiles.
# One random chamber is carved in each cell the plan uses. The boss arena takes a 2 x 2 block of cells.
# main  = how many chambers on the path from the start to the boss (the boss arena not counted)
# sides = how many optional side chambers branch off that path (extra loot, extra danger)
